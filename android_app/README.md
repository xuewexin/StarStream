# StarStream Android 客户端 (v3.2.7)

<p align="center">
  <img src="../docs/images/starstream_logo.png" width="112" alt="StarStream Android Logo">
</p>

**StarStream Android** 是星流媒体下载器的原生 Kotlin 移动端，无需依赖外部云端或桌面服务器即可在手机端独立完成网页嗅探、多类型文件下载、原生硬件音画混流、边下边看与外部在线预览。

## 主要特性

- **极简多内核内置浏览器**：干净无冗余启动页，支持多款桌面/移动内核切换，一键 **「身份刷新」** 轮换内核指纹并清理会话状态；支持网页与下载列表 **下拉刷新**。
- **数据持久化与防误退**：
  - 自动存储 **网页访问历史**，支持一键直达、单条删除与清空；
  - 离开浏览器或彻底退出重开均完整 **保留打开的标签页与当前浏览页面**；
  - 仅剩单个网页时左滑返回 **优先回到浏览器主页**，再返回才退出至下载列表；
  - 书签与历史区块支持 **一键折叠/展开**，支持新建不同名称的 **自定义收藏文件夹**。
- **全类型文件爬取 & 详细信息探测**：支持视频流（M3U8/MPD/MP4/MKV）、音频（MP3/M4A/FLAC）以及文档安装包（PDF/ZIP/7Z/APK）自由开关爬取；点击捕获条目可实时探测显示 **时长、类型、分辨率与体积**。
- **边下边看 & 外部在线预览**：内置本地防盗链 HTTP 代理，支持下载中 **边下边看** 及直接调用外部播放器在线预览网页视频。
- **灵活的并发与自定义目录**：支持配置同时下载任务数上限（1~6）、多线程并发（2~24）以及通过系统 SAF 选择手机任意 **自定义保存位置**。

## 本地编译

```bash
gradle assembleDebug --no-daemon
```
生成的 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。
